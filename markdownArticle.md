Hi! This is my first article written fully in **Markdown**.

## What is Markdown?

Markdown is a simple way to format plain text using a few symbols. You type normal text, add symbols like #, * or -, and an app that understands Markdown turns it into nicely formatted text.

I also learned that Markdown is platform independent, so I can write it on any computer or operating system. Websites like Reddit and GitHub support it too, and that's why every GitHub project has a `README.md` file.

## Things I Learned Today

### 1. Headings

To make a heading, you put a `#` in front of the text. More `#` symbols means a smaller heading:

- `#` is Heading Level 1 (the biggest one)
- `##` is Heading Level 2
- `###` is Heading Level 3

### 2. Paragraphs

If you just press Enter once, the lines stick together. To make a new paragraph, you need to leave a **blank line** between them.

See? This is a new paragraph because I left an empty line above it.

### 3. Bold and Italic

- To make text **bold**, wrap it in two stars: `**bold**`
- To make text *italic*, wrap it in one star: `*italic*`


### 4. Block Quotes

You use the `>` symbol to make a quote. My teacher gave us this example and I liked it:

> Hello World!
>
> World is a beautiful place!

The empty `>` line in the middle keeps both lines inside the same quote box.

### 5. Lists

There are two kinds of lists.

**Ordered list** (with numbers). These are my steps to make a README:

1. Wake up
2. Brush my teeth
3. Make breakfast
    1. Toast some bread
    2. Make tea
4. Go to class

**Unordered list** (with dashes). These are things I want to learn next:

- Pizza
- Biryani
- Desserts
    - Ice cream
    - Chocolate cake
- Fruits

To make an indented (nested) item, I just add four spaces before it.

### 6. Code

When I want to show something as code, I put it inside backticks like this: `This is a code`. It shows up in a different font, so people know it's code and not normal text. For example, `git status` is a command I use a lot now.

### 7. Links

To make a link, you put the text in square brackets `[ ]` and the website address right after it in round brackets `( )`, with no space in between.

Here is the guide I'm learning from: [Gooolge](https://www.google.ca)

### 8. Tables

Tables were the hardest part for me. You use pipes `|` to separate the columns and three or more dashes `---` under the header row. The colons `:` decide the alignment:

- `:---` means left aligned
- `:---:` means center aligned
- `---:` means right aligned

Here is a table from my networking class:

| Subnet | Network Address | Broadcast Address | Default Gateway |
|:-------|:---------------:|:-----------------:|----------------:|
| SN1    | 192.168.1.0     | 192.168.1.127     | 192.168.1.1     |
| SN2    | 192.168.1.128   | 192.168.1.255     | 192.168.1.129   |

### 9. Task Lists

To create Task List you add a dash, a space, and brackets `[ ]` to make a checkbox. Put an `x` inside to tick it off.
